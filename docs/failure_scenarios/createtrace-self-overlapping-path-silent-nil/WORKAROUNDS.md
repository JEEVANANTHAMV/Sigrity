# Workarounds: allegro_create_trace with Self-Overlapping Path Silently Returns Nil

## Verified Workaround

Pre-flight geometry check: before calling `allegro_create_trace`, verify that no two segments in the path share both an axis value (same X or same Y) AND an overlapping range on the other axis. A corrected, non-self-overlapping meander (verified point-by-point with this criterion) ran in the normal ~5-6s, `axlDBGetLength` confirmed the new real length as EXACTLY `3100.0` mil, and `Missing Connections: 0`/`Connection Completion: 100.00%`/correct Nets(75)/Pins(251) confirmed full board integrity.

The check algorithm: for the path as a sequence of points `[(x0,y0), (x1,y1), ..., (xn,yn)]`, for every pair of segments `(i, i+1)` and `(j, j+1)` where `i < j`:
- If both segments are horizontal (same Y): check if `yi == yj` AND the X-ranges `[min(xi,xi+1), max(xi,xi+1)]` and `[min(xj,xj+1), max(xj,xj+1)]` overlap (AND are not merely touching at an endpoint, which is valid — a corner).
- If both segments are vertical (same X): check if `xi == xj` AND the Y-ranges overlap.
- If one is horizontal and one is vertical: they intersect at a point, which is valid (a corner), NOT a self-overlap.

A self-overlap is when two COLLINEAR segments (same orientation) overlap in extent.

Evidence: `.forjinn/skills/sigrity-cad/SKILL.md:527-542` (Task 9, Gotcha #4 — "A corrected, non-self-overlapping meander (verified point-by-point: no two segments share both an axis value AND an overlapping range) fixed it").

## Prevention

1. When hand-designing a meander/detour path, verify point-by-point that no two segments share both an axis value AND an overlapping range on the other axis. Write the check as a pre-flight step before calling `allegro_create_trace`.
2. If you are generating the path programmatically (e.g., a meander calculation for length-matching), add a unit test that runs the collinear-overlap check on the generated path.
3. After trace creation, ALWAYS verify with `run_allegro_report(report_code="sum")` → `Missing Connections: 0`. If it is not 0, check for self-overlap (and, for older tool versions, the layer-string bug).
4. The failure signature (nil return, 0 segments, `Missing Connections: 1`) is identical to the (now-fixed) bare-layer-name bug. If you are using the current tool version and `Missing Connections` is 1, the most likely cause is self-overlapping path geometry.

## Remaining Gaps

- There is no tool in the suite that automatically validates a path for self-overlap before calling `axlDBCreatePath`. The pre-flight check must be done by the caller (in Python, before the SKILL call) or by inspecting the path visually.
- There is no tool that generates a length-matching meander automatically. The meander geometry must be hand-designed or generated by external code. The `allegro_get_net_length` tool can measure the current length (`axlDBGetLength`), and the caller can compute the required meander length, but the meander SHAPE must be designed by the caller.
- The self-overlap check is a geometric validity constraint on `axlDBCreatePath`, not a tool bug. Allegro's GUI routing tool would presumably have a similar constraint, but it would likely report the error interactively rather than silently returning nil.
